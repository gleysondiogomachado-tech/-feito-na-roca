💾 Backup e segurança

🔐 Seus dados

O aplicativo mantém os dados no armazenamento deste aparelho. Use o backup para guardar uma cópia dos clientes, pedidos, contas, estoque, produtos e demais informações.

Chave de armazenamento:
feitoNaRoca_v2

♻️ Restaurar backup

Escolha um arquivo JSON de backup criado pelo aplicativo. Antes de restaurar, o sistema cria automaticamente uma cópia dos dados atuais.

⏱️ Backup automático

Verificando...

Enquanto o aplicativo estiver aberto, uma cópia automática é criada periodicamente. São mantidas até 20 cópias.

⚠️ Importante

O backup automático fica neste aparelho. Para ter uma cópia realmente segura, use BAIXAR BACKUP e guarde o arquivo JSON em outro local, como iCloud Drive, Google Drive ou computador.
